# GiveWear – Kleiderspenden-Portal

## 📌 Projektbeschreibung

GiveWear ist ein fiktives Webportal zur Registrierung von Kleiderspenden für einen gemeinnützigen Verein.  

Spendende können auswählen, ob die Kleidung persönlich abgegeben oder abgeholt werden soll und ein gewünschtes Krisengebiet bestimmen.

Das Projekt wurde im Rahmen des Moduls **„Programmierung von Webanwendungsoberflächen“** erstellt.

## 🧱 Technologien

- CSS 
- JavaScript
- Bootstrap 5
